# Iron Dome

> Common asset. Up to eight copies. Rules: [Mechanics](../mechanics.md). Index: [Common cards](README.md).

A point-defense mount. The Phalanx CIWS is its own card.

| Field | Value |
| --- | --- |
| Chip cost | 2 |
| Stamp | 4 to Midnight |
| Health | 4 |
| Attack | 0 |
| Tags | Structure, Support |
| Type | Structure |

The Iron Dome does not make ordinary attacks. It occupies its slot and blocks commander strikes through that lane.

## Intercept

The first time an enemy Air unit attacks a friendly unit in this lane during a turn, that attack deals 1 less damage.

This card has no stage effect.
