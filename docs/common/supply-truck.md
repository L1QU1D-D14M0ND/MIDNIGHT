# Supply Truck

> Common asset. Up to three copies. Rules: [Mechanics](../mechanics.md). Index: [Common cards](README.md).

A canvas-backed truck with crates and a stretcher. It holds the lane and keeps the unit beside it standing.

| Field | Value |
| --- | --- |
| Chip cost | 2 |
| Stamp | 4 to Midnight |
| Health | 4 |
| Attack | 0 |
| Tags | Support |
| Type | Asset |

The Supply Truck does not make ordinary attacks. It occupies its slot and blocks commander strikes through that lane.

## Resupply

Once each turn, during your main phase, restore 2 Health to another friendly unit in the same lane.

This card has no stage effect.
