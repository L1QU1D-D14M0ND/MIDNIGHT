# Aegis Ashore

> Common asset. Up to eight copies. Rules: [Mechanics](../mechanics.md). Index: [Common cards](README.md).

A naval air-defense site from the prototype list. Basic form only.

| Field | Value |
| --- | --- |
| Chip cost | 4 |
| Stamp | 2 to Midnight |
| Health | 6 |
| Attack | 0 |
| Tags | Structure, Heavy |
| Type | Structure |

Aegis Ashore does not make ordinary attacks. It occupies its slot and blocks commander strikes through that lane.

This card has no stage effect.

Later, in the ability pass: once each turn, during your main phase, deal 2 damage to an enemy Air unit in this lane or an adjacent lane. This does not damage a commander.
