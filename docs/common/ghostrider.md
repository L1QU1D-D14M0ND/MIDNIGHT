# AC-130J Ghostrider

> Common asset. Up to eight copies. Rules: [Mechanics](../mechanics.md). Index: [Common cards](README.md).

A gunship. It is attack aircraft, so its stamp is **3 to Midnight**, with the choppers and the tanks. It is not a strategic bomber.

## Strafe the lane

When the Ghostrider attacks, it strikes the enemy front unit in its lane, then the enemy back unit in that lane. Skip an empty slot. A unit that dies on the first strike does not stop the second. If both slots are empty, it strikes the enemy commander once. Check the commander after each strike.

This card has no stage effect.
