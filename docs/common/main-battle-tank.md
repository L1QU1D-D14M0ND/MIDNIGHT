# Main Battle Tank

> Common asset. Up to eight copies. Rules: [Mechanics](../mechanics.md). Index: [Common cards](README.md).

The clock table authorizes main battle tanks at **3 to Midnight**. The prototype generated five of them with the same tags and random stats. They are one card.

The names are M1A2 Abrams, Leopard 2A7, T-14 Armata, Challenger 3, and Merkava Mk 4.
