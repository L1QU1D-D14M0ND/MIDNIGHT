# Field Gun

> Common asset. Up to three copies. Rules: [Mechanics](../mechanics.md). Index: [Common cards](README.md).

A towed artillery piece and its crew. It fires over the unit standing in front of the enemy.

| Field | Value |
| --- | --- |
| Chip cost | 4 |
| Stamp | 2 to Midnight |
| Health | 3 |
| Attack | 3 |
| Tags | Heavy |

## Shell the rear

When the Field Gun attacks, if the enemy back slot in its lane has a unit, the attack targets that unit. If that back slot is empty, the attack uses the normal lane order.

This card has no stage effect.
