# Pantsir-S1

> Common asset. Up to eight copies. Rules: [Mechanics](../mechanics.md). Index: [Common cards](README.md).

A mobile gun-and-missile air-defense vehicle. It is Armor, so it can hunt. Iron Dome is the Structure that only intercepts.

## Track the aircraft

When Pantsir attacks, it may choose an enemy Air unit in this lane or an adjacent lane. The attack hits that unit. If it does not choose one, the attack uses the normal lane order.

This card has no stage effect.
