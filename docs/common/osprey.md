# V-22 Osprey

> Common asset. Up to eight copies. Rules: [Mechanics](../mechanics.md). Index: [Common cards](README.md).

A tilt-rotor transport. It moves infantry between lanes. It does not fight.

| Field | Value |
| --- | --- |
| Chip cost | 2 |
| Stamp | 4 to Midnight |
| Health | 3 |
| Attack | 0 |
| Tags | Air, Support |
| Type | Asset |

The Osprey does not make ordinary attacks. It occupies its slot and blocks commander strikes through that lane.

## Lift

Once each turn, during your main phase, you may move a friendly Infantry unit into an empty slot in this lane from the same row of an adjacent lane.

This card has no stage effect.
