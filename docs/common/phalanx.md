# Phalanx CIWS

> Common asset. Up to eight copies. Rules: [Mechanics](../mechanics.md). Index: [Common cards](README.md).

A last-ditch gun mount from the prototype list. Basic form only. Iron Dome is the other point-defense card.

| Field | Value |
| --- | --- |
| Chip cost | 2 |
| Stamp | 4 to Midnight |
| Health | 3 |
| Attack | 0 |
| Tags | Structure, Support |
| Type | Structure |

The Phalanx does not make ordinary attacks. It occupies its slot and blocks commander strikes through that lane.

This card has no stage effect.

Later, in the ability pass: the first time each turn an attack would hit a friendly unit in this lane, that attack deals 1 less damage.
